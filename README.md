# Smart Doll : poupée éducative intelligente

Projet IoT (ISIMS) : une poupée qui pose des questions à l'enfant, évalue ses réponses et adapte la difficulté. Les parents suivent les progrès depuis une application web.

## Contenu du dépôt
- `firmware/` : code Arduino de la poupée (ESP32)
- `backend/` : serveur (leçons, résultats, authentification)
- `web-app/` : application web Angular pour les parents
- `docs/` : schéma de câblage et photos

## Installation
python3 -m venv /tmp/test-venv
source /tmp/test-venv/bin/activate
pip install -r requirements.txt
